# 严格递归缠论指标

面向 TradingView 免费版的单文件 Pine v6 缠论指标。理论口径以《缠中说禅教你炒股票》108 课及原作者答疑为基线；结构术语和验收规则分别记录在项目规格、`CONTEXT.md` 与 ADR 中。

## 功能

- 方向相关的 K 线包含、严格顶底分型、修订笔/严格笔、完整特征序列线段和 `L0-L3` 同构递归。
- 分层中枢固定 `ZD/ZG`、动态 `DD/GG`、延伸、离开候选/确认、离开失败和扩展候选。
- 盘整/趋势走势、盘整/趋势背驰、MACD `12/26/9` 同向面积与 DIF 极值附加证据。
- 每层独立计算候选/确认 1、2、3 类买卖点，并保存结构时间、确认时间、确认价格、延迟和失效边界。
- 焦点周期完整绘制，活动 K 线只写入隔离候选副本；最多四个更高参考周期独立计算 `L0-L2`，并把未收盘高周期预览与确认状态、共振和默认提醒隔离。
- 结构驱动的活动证据、层间共振、跨周期共振、冲突披露和父子包含式区间套。
- 最多五条走势终完美候选分支；只推演下一结构事件，不输出概率、目标价或完成时间。
- 简洁、标准、研究三种视图，TradingView、中国市场、色觉友好三套颜色，以及数据/可靠起点和对象预算诊断。
- 单一动态 `alert()` 出口；买卖点、背驰、共振、区间套和情景可筛选，JSON 字段使用稳定英文名称。

## 使用

1. 在 TradingView Pine Editor 中新建指标。
2. 粘贴 `chanlun.pine` 的完整内容并保存。
3. 选择标准 K 线图表后添加到图表。
4. 创建提醒时选择“任意 alert() 函数调用”。

默认自动选择四档更高参考周期。手动周期必须唯一且严格高于图表周期，否则指标会明确拒绝运行。更低周期的完整结构需切换图表周期查看。

确认结构只在对应行情周期收盘后进入确认层，冻结后不回改；橙色虚线/半透明对象属于候选状态，可能随未完成结构变化或消失。

## 约束

- 仅支持标准 OHLC K 线；Heikin Ashi、Renko、Kagi 等合成图表停止确认信号。
- 焦点周期最多递归到 `L3`，参考周期最多递归到 `L2`，面板会披露截断边界。
- TradingView 每类绘图对象最多 500 个；指标优先保留买卖点，再主动裁剪旧几何，历史点超过安全预算时会在面板明确提示。
- 指标表达结构，不提供策略下单、仓位、止盈止损、胜率或收益回测。
- 走势终完美是结构完整性约束，情景横向长度仅用于排版。

项目不提供策略回测、本地 Pine 编译器、PineTS 或其他语言参考引擎。TradingView 官方 Pine v6 编译器和图表运行结果是唯一兼容判据。

## 开发验证

每次测试都必须在 TradingView 中完成，并在记录结果后立即从图表移除测试指标，以释放免费计划的指标槽位。
