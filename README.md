# 严格递归缠论指标 course-v2

面向 TradingView 免费版的单文件 Pine v6 缠论指标。理论口径以《缠中说禅教你炒股票》108 课及原作者答疑为基线；结构术语和验收规则分别记录在项目规格、`CONTEXT.md` 与 ADR 中。

## 功能

- 方向相关的 K 线包含、严格顶底分型、唯一课件新笔、完整特征序列线段和 `T0-T3` 严格递归。
- 成笔同时要求合成 K 线分型中心距离 `>= 3`、原始端点索引距离 `>= 4`，并校验覆盖区间真实极值；不保留旧笔模式。
- 线段保存全部子笔的真实高低区间；笔只构造线段，三个连续已确认线段才建立最低 `T0` 中枢。
- 分层中枢固定 `ZD/ZG`、动态 `DD/GG`、延伸、离开候选/确认、离开失败和扩展候选。
- 盘整/趋势走势、盘整/趋势背驰、MACD `12/26/9` 同向面积与 DIF 极值附加证据。
- 走势采用 `forming -> qualified -> completion_candidate -> completed` 状态机；反向合格次级别走势或独立层级升级可冻结状态，升级结果不得反向自举其高级中枢的输入。
- 趋势背驰显式保存 `a+A+b+B+c` 与末中枢第三类点来源；盘整背驰不要求创新极值，MACD `12/26/9` 同向柱面积严格减弱是唯一硬条件。
- 每层独立计算候选/确认 1、2、3 类买卖点；二类点允许越过一类点并支持跨级来源，三类点在第五段完整回试时确认。
- 焦点周期完整绘制，活动 K 线只写入隔离候选副本；最多四个更高参考周期独立计算 `T0-T2`，并把未收盘高周期预览与确认状态、共振和默认提醒隔离。
- 结构驱动的活动证据、层间共振、跨周期共振、冲突披露和父子包含式区间套。
- 最多五条走势终完美候选分支；只推演下一结构事件，不输出概率、目标价或完成时间。
- 交易、简洁、标准、研究四种视图；交易视图只突出有效信号、关键中枢和短结构，并使用 9 行交易摘要面板。
- 分型、笔、线段、完成走势、中枢、背驰、买卖点、失效边界、候选、情景和状态面板均可独立隐藏；显示设置不改变计算或事件身份。
- 可选的历史生命周期账本（默认关闭，重负载）：开启后 `F/B/S/Tn`、背驰和买卖点在历史确认柱上逐事件写入不可变账本，重载重放同一迁移序列；免费计划的时间/内存预算通常无法与四参考周期同时承担。
- TradingView、中国市场、色觉友好三套颜色，以及数据/可靠起点和对象预算诊断。
- 单一动态 `alert()` 出口；买卖点、背驰、共振、区间套和情景可筛选，JSON 字段使用稳定英文名称。

## 使用

1. 在 TradingView Pine Editor 中新建指标。
2. 粘贴 `chanlun.pine` 的完整内容并保存。
3. 选择标准 K 线图表后添加到图表。
4. 创建提醒时选择“任意 alert() 函数调用”。

默认自动选择四档更高参考周期。手动周期必须唯一且严格高于图表周期，否则指标会明确拒绝运行。更低周期的完整结构需切换图表周期查看。

确认结构只在对应行情周期收盘后进入确认层，冻结后不回改；橙色虚线/半透明对象属于候选状态，可能随未完成结构变化或消失。

日常盯盘可选择“交易”显示预设。该预设会隐藏基础分型和笔，只保留最近线段、完成走势、关键中枢以及仍有效的背驰和买卖点；`1买·T1`、`2卖·T0` 等中文标签用于快速识别方向。需要复核结构来源时切回“标准”或“研究”。

## 约束

- 仅支持标准 OHLC K 线；Heikin Ashi、Renko、Kagi 等合成图表停止确认信号。
- 焦点周期最多递归到 `T3`，参考周期最多递归到 `T2`，面板会披露截断边界；`TF` 只表示 TradingView 行情周期，不与 `Tn` 固定映射。
- TradingView 每类绘图对象最多 500 个；指标优先保留买卖点，再主动裁剪旧几何，历史点超过安全预算时会在面板明确提示。
- 指标表达结构，不提供策略下单、仓位、止盈止损、胜率或收益回测。
- 走势终完美是结构完整性约束，情景横向长度仅用于排版。
- 本版本只输出严格递归结构真值，不包含同级别操作分解或多义性模式。

项目不提供策略回测、本地 Pine 编译器、PineTS 或其他语言参考引擎。TradingView 官方 Pine v6 编译器和图表运行结果是唯一兼容判据。

## 开发验证

每次测试都必须在 TradingView 中完成，并在记录结果后立即从图表移除测试指标，以释放免费计划的指标槽位。

当前发布门槛与结果记录见 `docs/tradingview-test-report.md`。历史 v1 截图只用于回归背景，不能证明 `course-v2` 定义成立。
