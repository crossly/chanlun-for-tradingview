# 历史回放只在结构边界重建

历史确认柱上的生命周期回放此前在每次末端候选延伸时也全量重建 `T0-T3` 递归并 reconcile 全部结构快照。同型更极端分型在趋势中高频出现，使历史回放次数与快照字符串构造呈平方级增长，叠加方向感知离开判定后焦点周期在免费计划 20 秒预算内超时（`RE10110`）。末端候选延伸只移动候选端点，不改变任何已确认前缀，其中间状态本就会被下一个结构事件或活动 K 线全量重建覆盖，因此不再标记结构变化：历史回放只在新笔建立或确认边界处重建。代价是生命周期账本不再记录同一候选笔的逐次延伸中间态，只保留其在结构边界处的最终形态；确认事件、替换事件与失效事件的身份和顺序不变。该裁剪符合 ADR 0034 资源优先级：确认结构真实性优先于候选中间态的历史密度。
