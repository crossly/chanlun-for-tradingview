# 以方向端点越界判定中枢离开

真实离开段起点位于中枢核心内部，整段区间必然与核心保持重叠，因此不能用"整段脱离核心"判据——那会把随后的反向回试误认成离开段，使一类点落在回试端点而非趋势极值、三类点晚一个摆动、二类点因方向序列错乱而缺失，且 MACD 面积比较变成异向对比。离开候选是方向端点越过对应核心边界的同向下层结构：向上离开要求上升段端点高于 `ZG`，向下离开要求下降段端点低于 `ZD`，不要求整段出核。下层结构方向交替，紧随离开候选的反向结构即回试：回试端点保持核心外侧（向上离开时不低于 `ZG`，向下时不高于 `ZD`）则离开确认；回试重返核心则记为失败尝试并入波动区间，且失败回试若自身越过另一侧边界，立即成为反向离开候选。中枢状态机、背驰与三类点使用同一判据。本 ADR 修正 ADR 0043 所依赖的离开识别口径，不改变其背驰绑定与确认规则。
