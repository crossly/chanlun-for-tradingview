# 从完成走势递归生成 T0-T3

笔只构造线段，三个连续已确认线段建立最低 `T0` 中枢。一个中枢或两个同向分离中枢只使走势获得盘整或趋势资格；背驰产生完成候选，反向合格次级别走势或层级升级才冻结完成边界。层级升级只能由三个已经独立完成的低级走势建立高级中枢后确认，不能反向制造该高级中枢依赖的低级完成构件；因此升级冻结走势状态和对应一类点，但不自举递归输入。三个连续完成 `Tn` 走势建立 `T(n+1)` 中枢。焦点计算 `T0-T3`，参考周期计算 `T0-T2`；行情周期与走势级别保持独立。本 ADR 替代 ADR 0010、0013、0014、0020、0021 的旧层级实现口径。
