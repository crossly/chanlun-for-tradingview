# 历史生命周期账本改为默认关闭的选项

历史生命周期账本要求在每个历史结构边界全量重建 `T0-T3` 递归、为全部结构构造带长字符串 ID 的快照并追加到只增不减的事件数组；四个参考引擎各自重复同样的流程。该组合在免费计划的 20 秒执行与内存预算内无法与方向感知离开判定并存（先后触发 `RE10110` 超时与 `Memory limits exceeded`）。逐事件历史迁移记录是审计能力，不是确认结构真实性的必要条件：账本关闭时，确认结构、买卖点、证据、共振、区间套与提醒完全不变，参考结构推迟到最后一根 K 线一次性重建，实时阶段仍只随参考周期收盘重建。因此账本改为显式输入，默认关闭；开启者自行承担付费计划的预算。按 ADR 0034 的资源优先级，确认计算真实性优先于历史事件密度。本 ADR 收窄 ADR 0044 的默认交付范围，不改变账本开启时的事件身份与 replay 语义。
